# SmartOrder · A마트 + B마트 통합 대시보드

A마트의 기존 React/Vite 화면 구조를 유지하면서 B마트 실데이터·수요예측·재고정책 결과를 동일한 메뉴 구조에 통합한 버전입니다.

## 통합 방식
- A마트 선택: `public/dashboard_full_data.csv` 사용
- B마트 선택: `public/bmart_dashboard_data.csv` 사용
- 좌측 메뉴/페이지 구조는 A마트 프로젝트를 기준으로 유지
- B마트 원본 서비스 결과와 원장 데이터를 A마트 화면이 사용하는 공통 데이터 스키마로 변환
- 기존 메뉴: 대시보드 / 품절 위험 / 재고 현황 / 수요 분석 / 발주 관리
- B마트의 2023-11-01 ~ 2024-01-30 서비스 결과 9,100행을 반영
- B마트 데이터에는 원본 서비스 결과의 재고·예측·권장발주 정보와 원장 데이터의 판매량/수요/프로모션/할인 정보를 결합

## 실행
```bash
npm install
npm run dev
```

## 주의
이 환경에서는 npm 의존성 설치가 완료되지 않아 `npm run build`를 실제 실행 검증하지 못했습니다. 소스 구조와 데이터 스키마는 정리해 두었으므로 로컬에서 `npm install && npm run build`로 최종 확인하면 됩니다.
